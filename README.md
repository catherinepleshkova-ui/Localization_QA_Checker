*A small Python tool for checking localization issues in game strings.*

**Features**
<li>Detects missing translations.
<li>Checks placeholder consistency, such as {player_name} and {gold}.
<li>Reads game strings from CSV files.

**Requirements**
<li>Python 3

**How to run**
<li>Clone or download this repository.
<li>Open the project folder in a terminal.

**Run:**
py checker.py

**Project structure**
<li>checker.py — validation logic.
<li>game_strings.csv — sample game strings.
<li>glossary.csv — localization glossary.
<li>tests/ — tests.
<li>reports/ — generated reports.
